# 本机远程协助“不再提示”

适用版本：0.5.0-beta.14；当前已开放被控能力的 macOS 客户端。

确认窗口增加默认不勾选的“不再提示（记住对此账号的本次允许范围）”。窗口使用 macOS 原生 AppKit 面板，不接受网页传入允许结果或复选框状态。

| 操作 | 当前请求 | 后续匹配请求 |
| --- | --- | --- |
| 不勾选，允许查看/控制 | 按所选范围允许 | 继续弹窗 |
| 勾选，允许查看 | 允许查看 | 查看自动批准；请求控制仍需弹窗 |
| 勾选，允许控制 | 允许控制 | 查看或控制自动批准 |
| 勾选或不勾选，拒绝/取消/按 Esc/关闭 | 拒绝 | 不新增记忆，下次仍需确认 |
| 请求过期、操作被取消、验证失败 | 不批准 | 不保存记忆 |

记忆按本机账号、登记设备、设备密钥版本及指纹、请求账号、两端认证版本和共享屏幕绑定。切换请求账号/本机设备、重建设备身份、认证版本变化或扩大已允许权限范围，都重新确认。当前请求方的连接 ID 和会话 ID 不作为长期标识；同一请求账号重新连接后可以复用已允许范围。

每次仍验证新的服务器签名请求、设备身份、请求有效期及防重放状态，再生成本次会话的原生同意；不复用旧会话签名、租约或媒体授权。系统录屏/辅助功能权限、在线要求、协助许可及停止保护不变。“不再提示”与临时/长期协助许可是两个独立设置。

本机记忆保存在应用数据目录的 `remote-consent-choices-v1.json`，每条记录用现有设备密钥签名，私钥继续留在操作系统凭据存储。记录读取或验签失败时恢复弹窗；不接受损坏或修改过的记录。仅在原生允许操作完整校验通过后写入，文件有数量和大小上限，使用原子替换。

“本机协助设置 → 恢复每次确认”清除本机所有已记住的允许选项，不结束当前已批准会话。清除与正在提交的记忆串行执行；清除期间尚未完成的旧确认不能重新保存记忆。

## beta.14 授权弹窗样式

按 UI 参考图改为 700 × 456 点的原生圆角白色面板，包含请求标题、设备/权限范围、浅蓝说明区、默认未勾选的记忆选项，以及拒绝/仅允许查看/允许控制三种按钮。仅查看请求只显示拒绝和允许查看，不能提升到控制。

当前签名协议提供请求账号 ID，没有可验证昵称或设备别名，因此标题显示实际账号 ID，设备标为“本机”；不会写死设计稿的示例姓名/设备名，也不使用网页提供的未签名昵称。完整已验证请求详情保留在面板提示信息中。恢复确认的说明指向当前实际的“本机协助设置”。

Return、Esc 和关闭仍按拒绝处理；达到已验证请求的真实截止时间会自动关闭，不延长授权时间。取消、拒绝和超时均不保存记忆。签名校验、原生同意、过期后二次校验及记忆存储逻辑不变；未开放的平台保留原生系统确认框。

离线预览（无联网、设备凭据、采屏、输入或记忆写入）：

```sh
cargo run --locked --manifest-path client-vue/src-tauri/Cargo.toml --example remote-consent-preview --features remote-control-harness
# 仅查看布局：在命令末尾追加 -- --view
# 2 秒过期关闭：在命令末尾追加 -- --expire
```
