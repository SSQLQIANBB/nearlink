## 环境与证据

记录主控系统/浏览器版本、被控系统/应用版本、是否不同网络、会话 ID、开始/结束时间。仅记录连接类型、帧率、码率、RTT、状态和固定错误码，不记录密码、TURN 凭据、签名载荷、完整 SDP 或用户输入正文。

使用独立空白测试文档，避免控制真实工作内容。主控网页保持前台；本机选择“允许控制”，主控点击“继续操作”。本轮不需要勾选“不再提示”。稳定性计时须在自动部署结束、应用版本不再变动后开始。
