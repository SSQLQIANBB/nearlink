# ToDesk 远控 UI 交互设计 v1

日期：2026-09-28。基线：0.5.0-beta.13 源码、当前平台验收边界，以及 https://www.todesk.com/special.html 的六类功能。

交付：12 张 2880×2000 PNG（设计坐标 1440×1000），本地可点击 `index.html`，热点定义 `pages.json`，可重复生成的 `render.py`。所有人物、设备和连接指标均为虚构示例；无生产凭据或真实桌面内容。

## 画板与主流程

00 全景 → 01 工作台 → 04 等待 → 05 被控本机允许 → 06 观看 / 07 控制 → 08 暂停恢复 → 09 结束。

被控准备：10 设备 → 02 能力/系统权限 → 03 联系人许可 → 上线。

11 为后续功能分组规划，不能当作已实现能力。系统原生授权窗口仅画交互示意，不能以 Web 弹窗替代实际原生同意。

## 关键交互约定

- Web 可作为主控；本机登记、上线和系统授权只向支持的桌面环境开放。
- 分别呈现缺引擎、不支持的平台、缺录屏、缺辅助功能。缺引擎不能诱导用户反复修改系统权限。
- 协助许可有效期 15 分钟、1 小时或长期，和单次会话、记住允许是三个不同概念。
- 不再提示默认关闭，仅记住本次实际允许的账号与权限范围。恢复每次确认不终止当前连接。
- 请求观看与控制必须保留不同 scope。本地原型的等待画板采用控制请求示例，观看请求须替换对应文案和授权动作。
- 请求拒绝/超时/取消/设备离线各自显示原因，不自动发起新请求。请求倒计时使用服务端实际截止时间。
- 观看时明确“尚未授予键鼠控制权限”。不显示“操作已暂停”作为观看状态。
- 操作暂停：先停止输入，保留有效画面；恢复动作按实际原因重新校验或申请授权，不能绕过本机同意。
- 媒体停滞、身份失效或连接关闭：停止会话，显示原因，重连必须生成新请求。
- 结束与停止协助始终可见；结束后释放键鼠、停止采屏并关闭通道。
- 撤销许可、恢复确认、移除设备只有成功返回后才能显示成功。移除设备和高影响运维操作需确认。
- 无障碍：可聚焦控件，焦点可见，状态不能只靠颜色，按钮至少 44px，高对比错误说明。

## 功能清单落位

基础连接与设备：01/02/03/10；跨平台与会话能力由检测决定。移动触控、安卓被控、多会话、摄像头、TV投屏为后续。
网络画质：06/07 的画面与连接信息区；画质、帧率、带宽和节点策略进入11规划。
协作：当前会话作为入口；文件、剪贴板、窗口共享、批注、打印、多人协作进入11，分别设计权限与进度/失败状态。
外设：11进阶设置，依平台实现逐项开放，禁止空入口。
运维：10设备页；分组、批量文件、终端、屏幕墙与无人值守进入11独立规划。
安全：02/03/05/08/09；隐私屏、录屏和审计为后续，不预先宣称可用。
