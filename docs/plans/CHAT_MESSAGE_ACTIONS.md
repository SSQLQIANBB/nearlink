# 聊天消息操作

版本：0.11.0-alpha.1。

单聊与群聊共用右键／触屏长按菜单：复制、转发、引用、多选、删除。文本复制到剪贴板并保留选中效果；图片和语音不提供文本复制。多选最多 100 条，支持逐条转发、删除和退出。

转发支持选择多个联系人或群聊和附加留言，按原列表顺序逐条发送。每个目标的每条消息保留独立的 `clientMessageId`，部分失败重试时跳过已经确认的条目。服务端根据 `{ kind, id }` 读取原消息，验证私信参与者／群成员权限，媒体文件无需重新上传。

引用使用 `{ kind, id }` 指定当前会话中的原消息。服务端生成发送人及正文摘要，通过 `__NEARLINK_REPLY__:` 信封存入现有消息正文；实时下发和历史查询均解码为 `quote`。已经发送的引用在原消息被本人删除后仍保留摘要。发送失败的本地消息保留引用，可随原发送入口重试。

删除为账号级隐藏，不是撤回。`message_deletions` 使用 `(userId, kind, messageId)` 复合主键，保留其他参与者的原消息；历史、离线、未读统计、群消息补拉和搜索查询均过滤当前账号的删除记录。`messages_delete` 确认后向该账号所有在线连接发送 `messages_deleted`，重新连接时页面重读历史。

部署时需同时更新前后端并重启后端。应用启动的 Sequelize sync 会创建新增的 `message_deletions` 表，无需修改现有消息表；生产数据库账号需要建表权限。旧前端不支持引用展示或在线删除同步，应更新客户端。

自动化覆盖服务端权限、删除幂等与引用序列化，前端触摸取消、菜单、多选、删除失败和转发重试。浏览器验收使用模拟接口；真实数据库、多设备在线同步及手机／Tauri 原生剪贴板仍需环境联调。
